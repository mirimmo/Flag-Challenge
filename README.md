# Flag Challenge V7.0
Upload all files to GitHub Pages. Test Voice before starting. Optional Gemini API key is remembered in browser local storage and sent directly to Google, never stored in the repository or saved game. Gemini model availability, Persian quality, free quota and browser CORS are not verified; Google may charge if billing is enabled. No robotic fallback: without a key a Persian device voice is required. Browser recognition remains experimental for bilingual answers. Saved games stay on the same browser.
